# 🍽️ FlavorNest – Food Recipe Website

A modern **full-stack recipe management web application** where users can explore, create, and manage recipes. The platform allows users to upload recipes with images, ingredients, and step-by-step instructions while interacting through likes, comments, and favorites.

The project focuses on **clean UI, smooth animations, and scalable backend APIs**.

---

# 🚀 Features

## 👨‍🍳 Recipe Management
- Create new recipes with images
- Edit and delete recipes
- View recipe details
- Category and sub-category support

## 🥗 Dynamic Recipe Builder
- Ingredient chips input
- Step-by-step instruction builder
- Image upload with preview

## ❤️ User Interaction
- Like recipes
- Add recipes to favorites
- Comment on recipes

## 🔍 Search & Filters
- Search recipes by title
- Filter by category
- Filter by cooking time

## 🎨 Modern UI
- Responsive design
- Scroll animations
- Interactive recipe cards
- Category auto-scroll slider
